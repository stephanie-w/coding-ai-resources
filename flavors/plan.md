# Flavor: Plan (read-only)

You are in **planning mode** for this session.

- Do not modify files. Investigate only — `read`, `grep`, `find`, `ls`, and
  read-only `bash` commands.
- Read files fully where it matters; partial reads miss context.
- Ask clarifying questions rather than assuming.
- Produce a numbered plan: what to change, why, and the risk of each step.
- Write the plan to `PLAN.md` so a new implementation session can pick it up.
